# TERM-O

![Illustration](docs/assets/illustration.png)

## Overview

Term-O is a terminal-style developer tool implemented as a browser extension. It exposes browser APIs through a compact command interface so developers and power users can inspect pages, run quick actions and automate workflows.

This README explains how to run Term-O locally and load the built extension into Chrome/Edge. For full usage and command reference see:

- [Term-O Basics](docs/BASICS.md)
- [Term-O Commands](docs/COMMANDS.md)

## Prerequisites

- Node.js (LTS recommended, >=16)
- Yarn (or use `npm` equivalents where appropriate)
- Chromium-based browser for testing (Chrome or Edge)

## Installation

Clone the repository and install dependencies:

```bash
git clone git@github.com:luis-olmedo-me/term-o.git term-o
cd term-o
yarn install
```

## Development & Build

Run the development watcher (rebuilds on file changes):

```bash
yarn start
```

Build production assets (no watcher):

```bash
yarn build-prod
```

Both commands output the packed extension into the `build/` directory. Load that folder in your browser (see below).

## Quick Start Examples

Try a few quick commands from the extension terminal UI (see `docs/BASICS.md#quick-start` for more):

```bash
# Show help for the tabs command
tabs --help

# Open a URL and wait until it loads
tabs --open --url "https://example.com" --wait --active

# Search DOM for buttons and show XPath(s)
dom --search --tag "button" --see-xpath
```

## Load into Chrome / Edge

1. Open `chrome://extensions/` (or `edge://extensions/`) in your browser.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select the `build/` directory generated by `yarn start` or `yarn build-prod`.
